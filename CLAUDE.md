# pogo-results

Generated scan JSON + the static GitHub Pages site for the [pogo-data](https://github.com/danwarddev/pogo-data) pipeline. Read pogo-data's `PROJECT.md` for the full picture, including the trade-log sync runbook (§9).

## Git

- **Commit directly to `main` and push immediately.** No feature branches, no pull requests. This applies even when a cloud session assigns its own working branch: check out `main`, commit there, and `git push origin main`. Don't commit on the assigned branch and merge later. GitHub Pages serves the live site from `main`, so a push there is the publish.
- The only exception is starting a genuinely new feature/process, when dan may ask for a branch.
